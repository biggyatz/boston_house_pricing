# Legacy: Boston House Pricing (2024)

The original project in this repository: a linear regression on the Boston Housing dataset (test R² 0.711, RMSE 4.64 $k), served by Flask (`app.py`), packaged with `Dockerfile` and previously deployed on Heroku and Render.

```bash
cd legacy-boston
pip install -r requirements.txt
python app.py
```

It has been replaced by the Nepal property estimator described in the [main README](../README.md).
